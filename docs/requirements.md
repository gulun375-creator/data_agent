## 1. 项目概述

### 1.1 项目目标

构建一个基于大语言模型（LLM）的数据分析 AI Agent，支持用户通过自然语言问答的方式完成数据分析任务。降低数据分析门槛，让非技术用户也能通过对话获取数据洞察。

### 1.2 目标用户

| 用户角色 | 描述 | 核心诉求 |
|---------|------|---------|
| 业务分析师 | 需要频繁查看数据指标，但 SQL/Python 能力有限 | 用自然语言快速获取数据洞察 |
| 产品经理 | 需要数据支撑决策，不愿等待数据团队排期 | 自助式数据查询和可视化 |
| 运营人员 | 需要日常监控关键指标、生成报表 | 自动化报表和异常检测 |
| 数据工程师 | 需要快速探索数据、验证假设 | 加速 EDA（探索性数据分析）流程 |

### 1.3 核心价值

- 自然语言交互，零代码门槛
- 自动生成并执行分析代码（SQL / Python）
- 结果可视化呈现（图表 + 文字解读）
- 多轮对话支持，逐步深入分析

## 5. 用户场景（User Stories）

### 场景 1：上传 CSV 进行快速分析

> **作为** 业务分析师  
> **我想要** 上传一份销售数据 CSV，然后用自然语言提问  
> **以便于** 快速获取数据洞察，而不需要写代码

**示例对话**：
```
用户：[上传 sales_2025.csv]
Agent：已加载数据文件，共 15,234 行 x 12 列。字段包括：日期、产品名称、销售额、地区...
      数据时间范围：2025-01 至 2025-12。是否需要我先做一个整体概览分析？

用户：上个季度销售额最高的产品是什么？
Agent：上个季度（2025 Q4）销售额 Top 5 产品如下：
      [柱状图]
      1. 产品A - ¥2,340,000
      2. 产品B - ¥1,890,000
      ...
      产品A的销售额领先第二名约23.8%，主要集中在华东地区。

用户：按月拆分看一下产品A的趋势
Agent：[折线图：产品A月度销售趋势]
      产品A在10月达到峰值（¥920,000），11月略有回落，12月恢复增长...
```

### 场景 2：连接数据库进行查询

> **作为** 产品经理  
> **我想要** 连接公司数据库，用自然语言查询用户数据  
> **以便于** 自助获取产品指标，不依赖数据团队

**示例对话**：
```
用户：连接我的数据库 [输入连接信息]
Agent：已成功连接数据库，发现 23 张表。核心表包括：users, orders, products...

用户：过去30天的日活跃用户趋势怎么样？
Agent：[折线图：DAU 趋势]
      过去30天平均 DAU 为 12,450，整体呈上升趋势（+8.2%）。
      3月15日出现峰值（18,200），可能与营销活动相关。

用户：这些活跃用户的地区分布呢？
Agent：[饼图：用户地区分布]
      华东地区占比最高（35.2%），其次是华南（22.1%）...
```

### 场景 3：自动生成数据报告

> **作为** 运营人员  
> **我想要** Agent 自动生成周度运营报告  
> **以便于** 减少手动整理数据的时间

**示例对话**：
```
用户：帮我生成本周的运营周报，关注 GMV、订单量、用户增长
Agent：正在分析本周数据... 已生成运营周报：
      
      📊 本周运营周报（2026-03-23 ~ 2026-03-29）
      
      一、核心指标概览
      - GMV: ¥5,230,000（环比 +12.3%）
      - 订单量: 8,450 单（环比 +8.7%）
      - 新增用户: 2,100（环比 -3.2%）
      
      二、关键发现
      ...
      
      [导出为 PDF]
```
